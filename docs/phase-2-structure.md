The more I practice 'mkdir', 'touch', 'ln -s', 'cp' and 'mv' the faster I get.

It's actually a great way to engrain version control, which is very important in production because of the many files/assets you're handed after recording.

I really enjoyed making a templates folder, then copying it over to a show's folder and then renaming that file something specific to the show ('mv shows/after-hours/ep01/edit/show-notes.txt shows/after-hours/ep01/edit/ep01-notes.txt').

I also practiced previewing my file structure before applying it, which proved useful in identifying any unintentional typos and formatting I changed my mind on.
(ex. 'echo shows/{show-name1,show-name2}/ep{01..03}/{raw,edit,final})

As you can see, it's a good way to see how many directories and subfolders would be useful to have.
